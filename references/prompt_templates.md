# Prompt Templates — 情绪表演Prompt模板与案例

## 四层万能模板

```
【Layer 1 — 公共约束】
竖屏9:16，写实真人情绪表演视频，固定机位，中近景半身构图，
[背景描述]，保持人物身份、脸型、服装不变。镜头稳定，人物面部清晰，
重点表现[当前情绪相关的面部区域]。不要字幕、不要水印，
不要夸张表情，不要AI僵硬。

【Layer 2 — 情绪定位】
人物用「[情绪标签词]」的情绪说[台词]。
整体[一句话描述情绪基调]。情绪强度从[X]分到[Y]分，[变化方式]。

【Layer 3 — 逐秒面部拆解】
0到1秒：[主导面部信号 + 微弱辅助信号]
1到2秒：[转折点：哪个局部动作先发生，强度如何上升]
2到3秒：[情绪推进：增加1-2个辅助动作，但不要全脸同步变化]
3到4秒：[台词语音描述 — 音高+音量+质感]，口型与停顿协调
4到6秒：[余韵：关键动作回落、保留的情绪泄漏点]

> 内部先用FACS检查动作组合、强度和先后顺序，最终仍以自然语言输出，不直接堆AU编号。

【Layer 4 — 核心防翻车】
重点：[核心目标一句话]。[列举最可能翻车的2-3个方向]。
```

**变化方式**选项：慢提 / 迅速升 / 隐忍 / 安静保持 / 先压后炸

## 完整迁移示例："笑着说我没事"

```
竖屏9:16，写实真人情绪表演视频，固定机位，中近景半身构图，灰色纯净背景，
保持人物身份、脸型、服装不变。镜头稳定，人物面部清晰，
重点表现眼神游离、嘴角勉强和呼吸不稳。不要字幕、不要水印，
不要夸张表情，不要AI僵硬。

人物用「强撑欢笑」的情绪说"我没事"。
整体是明明有事却硬说没事，笑比哭更让人心疼。情绪强度从4分到7分，压抑式慢升。

0到1秒：人物听到对方的话，眼神先顿一下，稳住表情，嘴角微微往上撑出一个笑。

1到2秒：笑先到位，但眼睛没有一起笑。眼眶轻微泛红，下眼睑有一点点发紧，
视线不敢完全对着对方。

2到3秒：呼吸变浅，胸腔轻微起伏一下。嘴唇轻轻抿住又松开，做出口型准备。

3到4秒：带着气声说出"我没事"，声音轻、短，尾音微微下沉。
说到"没"字时嘴角的笑有一瞬间撑不住。口型清楚但不拖音。

4到6秒：说完后迅速把笑重新撑起来，但眼睛已经出卖了一切——眼神湿润、
闪烁、有一瞬间飘走。嘴角继续维持笑意，但脸部其他肌肉是松的。

重点：笑比哭更惨——嘴在笑，眼睛在哭。不要嚎啕大哭，不要面部扭曲，
笑要撑得住但撑不稳。
```

## 六个情绪版本同一台词"滚"

六版使用完全相同的公共约束框架，仅替换情绪核心段落。

### 第1版：笑骂（强度4分，保持平稳）

```
人物用「笑骂」的情绪说一个字："滚"。整体不是愤怒，也不是开心大笑，
而是带一点亲近关系里的无奈、嫌弃、轻微责怪，像对熟人说"你真讨厌"。
情绪强度控制在4分，轻松、有点俏皮，但不能油腻。

0到1秒，人物先看向镜头前方，眼神里带一点"你又来了"的无奈，
眼睛微微放空，脸部还没有完全笑开。眉毛可以轻轻挑起一侧，嘴角先压住，不要立刻笑。

1到2秒，眼神先活络，带一点轻微责怪和熟悉感，明明有点气但又觉得好笑。
下眼睑轻轻提起，嘴角慢慢扯出不经意的笑意。

2到4秒，人物带着一点忍笑说出一个字："滚"。口型清楚，声音感轻、短、
带一点笑意，尾音微微上扬，不是厚重的怒音。说"滚"的时候嘴角带笑，
但眼神里仍有轻微的嫌弃。

4到6秒，说完后人物轻轻收住笑，头部可以微微偏一下，
脸部重新看向对方，表情是"拿你没办法"的感觉。嘴角保留一点弧度，
眼神亲近、俏皮、一点嫌弃。

重点：眼眸先亮，嘴角后笑，说"滚"时笑着骂人。不要大笑，不要翻白眼，
不要嗔怒成真生气。
```

### 第2版：失望（强度3→6分，慢提）

```
人物用「失望」的情绪说一个字："滚"。整体是原本心里还有期待，
但对方的行为让她彻底失望。不是崩溃，不是愤怒大喊，而是冷下去、暗下去，心里落空。
情绪强度从3分慢提到6分。

0到1秒，人物先看向镜头前方，眼神里还有一点等待和期待，脸部保持平静，
嘴唇自然闭合。

1到2秒，你听到一个让她失望的答案，眼神先停住半拍，眼里的光慢慢暗下来，
鼻翼轻轻收缩，眼皮微微压低。

1到3秒，眼神慢慢失去聚焦，视线穿过镜头看向很远的地方。眨眼减少，
眼睛不再有光泽，眉峰耷拉，呼吸变得无力。

2到4秒，嘴角一点失去支撑，轻轻向下垮，呼吸沉下去。她看着对方，
眼神不再有期待，而是空落、冷、完全空。

3到4秒，嘴角缓缓往下微放，唇齿轻轻闭合微微松开，
整张脸松弛没有力气再做任何回应。

4到5秒，不带委屈说出一个字："滚"。口型清楚，但声音感低、轻、尾音下沉，
已经不想再解释。不是吼出来，是失望到不想多说。

5到6秒，说完后轻轻收回目光，眼神静下来，表情定格在失落和冷漠之间。
不想再继续对视，不想再看对方。

重点：失望不是哭，是眼神慢慢冷掉。说"滚"要低、冷、轻，
把握最后一点期待消散的感觉。不能哭喊，不能愤怒。
```

### 第3版：委屈（强度4→6分，隐忍）

```
人物用「委屈」的情绪说一个字："滚"。整体明明是很委屈，但还不想，
也不愿真的发火，也不想让对方看见自己眼泪。情绪强度从4分到6分，重点是隐忍。

0到1秒，人物先看向镜头前方，眼神有一点受伤和不服，心里憋着话。
嘴唇轻轻闭住，脸部还在克制。

1到2秒，眼尾开始泛红，视线想对着对方，但又不敢看太久，
可以轻轻偏一下。眉头往中间轻轻皱，不能大幅度。

2到3秒，下眼睑慢慢涨起，眼眶出现轻微湿润感，鼻尖像有一点发酸。
嘴唇轻轻抿住，嘴角向内收，下巴有一点点发紧。

3到4秒，带着委屈说出一个字："滚"。口型清楚，但声音不能硬，
要有一点哽住、发紧、忍着哭腔的感觉。这个"滚"不是攻击别人，而是保护自己。

4到6秒，说完后轻轻吸一口气，眼神重新抬起来看对方，
眼里还有委屈和倔强。嘴唇继续抿住，不让眼泪掉下来。

重点：先忍，再抿嘴，再说"滚"。这个"滚"要委屈到极限后的自我保护，
不要大哭大闹。
```

### 第4版：心如死灰（强度6分，极其安静）

```
人物用「心如死灰」的情绪说一个字："滚"。整体不是大哭，也不是愤怒，
而是已经失望到没有反应，彻底麻木，整个人放空。情绪强度6分，但表现方式极其安静。

0到1秒，人物安静站着，看向镜头前方，身体几乎不动。
脸上没有明显哭，也没有愤怒，只有一种沉重的安静。

1到3秒，眼神慢慢失去聚焦，视线穿过镜头看向很远的地方。
眨眼减少，眼睛不再有光，眉峰耷拉，呼吸变得无力。

3到4秒，嘴角缓缓往下微放，唇齿轻轻闭合微微松开，
整张脸松弛没有力气再做任何回应。

4到5秒，很轻、很平淡地说出一个字："滚"。口型清楚，但声音没有起伏，
没有情绪爆点，像已经彻底心冷。眉眉短、淡、空。

5到6秒，说完后人物仍然盯着对方，呼吸变重，嘴唇重新压住，
眼里还有余念。身体可以微微承压，但不要大幅晃动。

重点：先压忍，再爆发。这个"滚"要弱、细、重，像到极限后的命令，
不要从第一秒就乱。不是大哭，不是愤怒，是失望到没有反应。
```

### 第6版：崩溃（强度5→9分，迅速升）

```
人物用「崩溃」的情绪说一个字："滚"。整体不是单纯哭，
而是已经压抑到临界点，情绪完全崩掉，像被逼到无法忍耐。
情绪强度从5分迅速升到9分。

0到1秒，人物先看向镜头前方，眼神已经有一点失守，快要撑不住。
脸部还在努力维持，但呼吸开始不稳。

1到2秒，眼神不再稳定聚焦，视线涣散，眉毛往上又收紧，
眼睫控制不住，鼻翼和嘴角出现失控起伏。

2到3秒，情绪突然炸开，眼泪瞬间涌上来，眼眶通红，呼吸大段起伏，
声音从压抑猛地炸开。

3到6秒，带着哭腔、失控地吼出一个字："滚"。声音撕裂、发颤，
夹杂压抑许久的哭音。说完后肩膀轻微颤抖，眼泪滑落。

重点：前期隐忍克制，后期瞬间崩溃。哭腔厚重，声音冲击力强。
```

## 关键设计规律

六版共用结构：公共约束 完全一致 + 情绪定位 差异 + 逐秒拆解 核心差异 + 防翻车 差异。

情绪感染力来源：描述"从A状态变化到B状态"的过程，而非"始终处于B状态"。面部动作要有主次和时序，先用FACS做内部动作骨架，再写成自然表演语言。
六版没有一版是从第一秒就进入目标情绪的——笑骂先无奈再笑，失望先期待再冷，
委屈先克制再绷不住，心死先安静再放空，崩溃先维持再炸开。
