# Emotion Keywords — 情绪关键词分级体系

## 核心原则

永远用生理细节替代抽象情绪标签。AI视频模型是视觉模型，"悲伤"对它是模糊的，但"眼眶湿润+下眼睑涨起+鼻尖发酸"是明确唯一的视觉信号。


## FACS转译原则

本词库继续承担“自然语言表演表达”职责。FACS用于内部动作校验，不替代本词库。生成时优先将AU转译为模型可理解的自然语言，并保留动作的先后、强弱和局部性，不输出成一串AU编号。

## 面部五要素高频词库

生成情绪Prompt时，从以下五组要素中各选至少一个来描述当前秒段的面部状态：

### 1. 眼神/瞳孔

| 关键词 | 情绪指向 | 强度 |
|--------|---------|------|
| 失去聚焦、放空、定住 | 失望、麻木、思考 | 中 |
| 光暗下来、不再有光泽 | 失落、心冷 | 中→高 |
| 飘忽、闪烁、游离 | 不安、心虚、犹豫 | 低→中 |
| 先亮后活络，透着光 | 喜悦、期待 | 低→中 |
| 穿过镜头看向远方 | 麻木、放空、决绝 | 高 |
| 不敢对视，偏开视线 | 委屈、害羞、心虚 | 中 |

### 2. 眼睑/眼眶

| 关键词 | 情绪指向 | 强度 |
|--------|---------|------|
| 下眼睑轻轻提起 | 笑意将出未出 | 低 |
| 眼尾泛红、慢慢发红 | 委屈、悲伤前兆 | 中 |
| 眼眶湿润、泛起水光 | 感动、悲伤 | 中→高 |
| 下眼睑慢慢涨起 | 即将落泪 | 中→高 |
| 眼眶通红 | 崩溃、大哭 | 高 |
| 眼皮微微压低 | 失望、疲惫 | 低→中 |
| 眨眼减少、几乎不眨 | 麻木、呆滞 | 高 |

### 3. 眉峰

| 关键词 | 情绪指向 | 强度 |
|--------|---------|------|
| 轻轻挑起一侧 | 无奈、调侃、质疑 | 低 |
| 往中间轻轻皱 | 委屈、困惑 | 中 |
| 眉峰下压 | 压抑的愤怒 | 中 |
| 眉间褶皱加深 | 愤怒升级 | 中→高 |
| 眉峰耷拉、毫无支撑 | 失望、疲惫到极点 | 中→高 |
| 往上又收紧 | 快要撑不住 | 中→高 |

### 4. 嘴角/唇

| 关键词 | 情绪指向 | 强度 |
|--------|---------|------|
| 扯出不经意的笑意 | 忍笑、愉悦 | 低 |
| 压住笑、抿住 | 克制笑意 | 低 |
| 轻轻抿住、嘴角向内收 | 委屈、隐忍 | 中 |
| 向下垮、失去支撑 | 失望、无力 | 中→高 |
| 微微松开、松弛 | 放弃、麻木 | 高 |
| 咬紧、下颌紧绷 | 愤怒、克制 | 中→高 |
| 颤抖、控制不住 | 情绪失控边缘 | 高 |

### 5. 呼吸/声音

| 关键词 | 情绪指向 | 强度 |
|--------|---------|------|
| 呼吸变轻、变得无力 | 失望、疲惫 | 中 |
| 沉下去、重重呼出 | 释放、下决心 | 中 |
| 不稳、出现起伏 | 情绪波动前兆 | 中 |
| 哽住、发紧 | 强忍哽咽 | 中→高 |
| 大段起伏 | 情绪失控 | 高 |
| 突然炸开 | 崩溃爆发 | 高 |
| 轻轻吸气 | 收拾情绪、重新振作 | 低 |
| 呼吸变重、嘴唇重新压住 | 压抑后的余韵 | 中 |

## 微表情关键词（替代大情绪，更自然）

来源：Naviya 微表情 Prompt 指南（2026.6）

**开心类**：faint smile（淡淡微笑）、almost smiling（将笑未笑）、softening around the eyes（眼周柔和）、corners of mouth carry faint hint of amusement（嘴角一丝愉悦）

**克制愤怒类**：jaw tight（下颌紧绷）、lips pressed together（嘴唇抿紧）、controlled frustration（克制的挫败）、narrowed gaze（目光收窄）

**悲伤低落类**：distant gaze（眼神放空）、slow blink（缓慢眨眼）、breath caught briefly（呼吸短暂停顿）、eyes slightly unfocused（眼神略微失焦）

**紧张害羞类**：quick glance away（迅速移开视线）、fingers fidgeting with sleeve（手指摩挲衣袖）、lips press together before faint smile（抿唇后浅笑）

## 情绪过渡词

Seedance 2.0 支持情绪过渡，用于同一镜头内的情绪转变：

- `starts surprised then breaks into laughter`（先惊讶后大笑）
- `from despair to quiet resolve`（从绝望到平静的决意）
- `eyes soften, then a tear falls`（眼神变柔，然后一滴泪落下）
