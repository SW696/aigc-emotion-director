# Directing Tips — 导演叙事与音画协同技巧

## 镜头语言情绪对照表

| 情绪目标 | 运镜方式 | 景别建议 |
|----------|----------|----------|
| 不安/紧张 | 轻微手持晃动 | 近景 |
| 浪漫/投入 | 缓慢推近 | 中景→特写 |
| 失落/离开 | 缓慢拉远 | 特写→远景 |
| 孤独/沉思 | 静态广角、缓慢拉开 | 远景+固定 |
| 冲突/对峙 | 快速推轨、荷兰角 | 双人近景 |
| 史诗/震撼 | 无人机航拍、升降镜头 | 大远景 |

## BGM情绪配合

| 音乐元素 | 情绪效应 |
|----------|----------|
| 快速节奏(120-160 BPM) | 兴奋、紧迫 |
| 慢速节奏(60-80 BPM) | 悲伤、平静 |
| 大调 | 快乐、明亮 |
| 小调 | 严肃、忧郁 |
| 弦乐 | 温暖、悲伤、宏大 |
| 钢琴 | 细腻或戏剧张力 |
| 铜管 | 英雄、胜利 |
| 渐强 | 情绪积累 |
| 渐弱 | 内省、消逝 |
| 策略性留白 | 情绪沉淀 |

**BGM音量**：设为人声的 **15-20%**，只托底不抢戏。

## "一分钟法则"

如果无法在60秒内用简单故事让观众有感触，10分钟史诗片只会稀释情感。

案例："父亲离开家去太空，女儿在他缺席下长大，他很想念她。"——不需要太空政治和战斗。

## AI视频角色一致性参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| IP-Adapter 权重 | 0.6-0.8 | 过高画面僵硬，过低特征丢失 |
| Denoising Strength | 0.4 以下 | 防闪烁，保证帧间一致性 |

## "先锁风格、先出图再视频"工作流

1. 第0步：定义统一风格锚点（正负面风格描述）
2. 第1步：图像模型生成角色设定图（Seedream/GPT Image 2）
3. 第2步：以角色首帧为参考进行图生视频（Seedance 2.0）
4. 第3步：七大架构层级推进——技术基底→氛围→角色锁定→场景→声音→时间线→约束
