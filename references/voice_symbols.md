# Voice Symbols — 配音符号情绪对照表

适用于 ElevenLabs v3 Audio Tags、ChatTTS、CosyVoice 等支持情绪标注的TTS引擎。

## 完整符号对照表

| 符号 | 声音开场描述 | 气息/停顿时长 | 典型情绪场景 | 实操使用建议 |
|------|-------------|-------------|-------------|-------------|
| `……` 省略号 | 声断气流，气流微弱持续 | 停顿0.5-2秒 | 犹豫、思考、害羞、虚弱、话未说完、恐惧卡壳 | 制造空白留白，增添情绪留白 |
| `！` 感叹号 | 声带加压，气流爆破，音调拔高，无停顿缓冲 | 无 | 愤怒、兴奋、惊恐、命令、警告 | 强情绪爆发，避免滥用 |
| `？` 问号 | 每句末尾上扬，气息悬浮等待回应 | 无 | 疑问、反问、试探、挑衅、惶惑 | 双问号??可增强不可置信感 |
| `——` 破折号 | 前字音拉长1.5-2倍，后接截断/骤停 | 无 | 声音中断、转折、颤音、欲言又止、被打断 | 情绪割裂感强，适合戏剧化表达 |
| `~` 波浪号 | 单字内音高滑动上扬，尾音拖长带气声 | 无 | 撒娇、诱惑、轻佻、慵懒、欢快 | 区分下划线_的"平拉长" |
| `**` 星号 | 字词短促断开，节奏如切音效 | 无 | 强硬、压抑怒吼、机械式进出、冷冰冰列举 | 一字一顿，增强压迫感 |
| `''` 单引号 | 音量偏低，语速缓慢，语气更轻 | 无 | 自言自语、内心独白、悄悄诉说、心理补充 | 表现私密感与心理活动 |
| `：` 冒号 | 触发台词过渡，开篇对应发声状态 | 停顿0.3秒 | 标记对话内容，常与引号连用 | 是"说话前奏"的关键符号 |
| `；` 分号 | 停顿略长于逗号(约0.3-0.4秒)，气息不断 | 无 | 逻辑转折停顿、故作深沉叙述 | 用于复杂长句中的语义分层 |
| `()` 括号 | 音量降低30%-50%，语速加快，常为气声/心理活动 | 无 | 补充说明、内心吐槽、心虚暗语、动作提示 | 非主台词，起辅助作用 |
| `[]` 方括号 | 标注非台词指令，如[停顿2秒]、[气声] | 无 | 状态切换、镜头描述、结构化控制 | 系统级指令容器，不发音/特殊处理 |
| `<>` 尖括号 | 标注特殊音效/发声方式，如<深呼吸>、<破音> | 无 | 插入非语言声音、强调生理动作 | 增强真实感与细节表现 |
| `/` 斜杠 | 语音中断或自我纠正，音色短暂重叠模糊 | 无 | 结巴、说错改口、欲言又止、快速切换 | 表现出言不流畅状态 |
| `""` 双引号包围 | 语气显著变化：更低、更慢、更僵 | 无 | 刻意装演、反讽挖苦、情绪突变 | 强调标记，非标准标点广泛使用 |
| `_` 下划线 | 音节拉长音值不变 | 无 | 疲惫倦怠、不情愿回应、机械拉长 | 与波浪号"上扬拉长"形成对比 |
| `#` 井号 | 标注状态标签，如#whisper、#cry | 无 | 快速切换情绪模式，启用特定风格 | 社区通用标签，部分系统支持 |
| `-` 连字符(短横) | 句末声音渐渐消失，不突然切断 | 无 | 入睡前语、虚弱至极、濒死低吟呼唤 | 表现"消散"感，非戛然而止 |
| `……！` 省略+感叹 | 压抑后的小爆发，停顿后突然加重 | 无 | 想发火又忍住，最后忍不住 | 情绪压抑后的释放 |
| `！…` 感叹+省略 | 爆发后迅速泄气，声音从高突然落气 | 无 | 激动过后瞬间低落，最后没忍住 | 强落差情绪 |
| `？！` 问号+感叹 | 先迟疑再爆发 | 无 | 震惊、难以置信、逼迫质问 | 强化冲突与压迫感 |

## 使用示例

**轻声细语场景**：
```
#whisper "你觉得……这样做，真的对吗？" [停顿1秒] <深吸一口气> "我~不这么认为。"
```
→ 轻声细语→尾音上扬→停顿深呼吸→撒娇式反驳

**压迫式警告场景**：
```
"你给我**听**好了——这事儿，没完！！……" [气声]
```
→ 一字一顿→破折号拉长骤停→双感叹强爆发→省略号气声收尾

## TTS 参数推荐

| 场景 | ElevenLabs Stability | 语速调整 | EQ |
|------|---------------------|----------|-----|
| 强烈情感(广告/冲突) | 0.45-0.55 | -3%至-5% | — |
| 教学/课程 | 0.65-0.70 | -12%至-15% | 150-300Hz +2-3dB |
| 纪录片/叙事 | 0.60-0.65 | -10%至-12% | 150-300Hz +2-3dB |
| 短视频旁白 | 0.55-0.60 | -3%至-5% | 衰减6000Hz+ |

中文配音建议统一调慢 8%-15%，减少"AI配音感"。段间留 200-300ms 间隙，头尾加 0.3 秒淡入淡出。
