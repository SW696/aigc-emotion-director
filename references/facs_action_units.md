# FACS Action Units — AI人物表演内部编码层

## 目的

FACS（Facial Action Coding System）在本Skill中作为**内部面部动作编码与一致性校验层**使用。
它不是情绪词典，也不是最终Prompt语言。先用AU判断“脸上发生了什么”，再把编码翻译成自然、可执行的中文表演描述。

核心链路：

`情境/台词 → 情绪状态 → AU组合 → 强度与时序 → 自然语言表演Prompt`

最终给视频模型的Prompt默认不显示AU编号，除非用户明确要求使用FACS编码。

## 强度编码

FACS常用A-E表示动作强度递增。对于AI视频Prompt，建议这样理解：

- **A**：极轻微，刚刚出现，容易成为情绪泄漏点。
- **B**：轻微、可感知，但仍然克制。
- **C**：中等，镜头中稳定可见。
- **D**：明显，已经成为主要表演动作。
- **E**：极强，通常只在明确爆发或极端状态使用。

常规真人表演优先A-C。不要为了“有FACS”而把所有AU设成D/E。

## 时序规则

不要只记录“有哪些AU”，还要记录它们的进入顺序：

`neutral → onset → build → apex → release`

例如“强撑欢笑”：

`AU12(B)先出现 → AU6(A-B)没有完全跟上 → AU7(B)轻微收紧 → AU24(A-B)短暂压住 → AU12回落`

转译成自然语言就是：

> 嘴角先勉强提起，但眼周没有同步放松；下眼睑轻微发紧，随后嘴唇短暂抿住，笑意撑不住后慢慢回落。

这里的关键不是把AU全部念出来，而是保留**先后关系**。

## 常用组合模式

### 克制愤怒

常见组合：`AU4 + AU7 + AU23/AU24`

转译重点：眉间收紧、目光变窄、嘴唇压住、下颌有张力。

不要自动升级成AU27、大张嘴或高强度动作，除非剧情明确要求爆发。

### 悲伤/失落倾向

常见参考：`AU1 + AU4 + AU15`，可根据人物状态辅以眼睑收紧、缓慢眨眼、嘴唇压住等动作。

注意：悲伤不是单一AU组合，必须结合呼吸、视线和情绪转折判断。

### 微笑/强撑微笑

常见参考：`AU12`，自然笑意可伴随`AU6`；强撑时可出现“AU12存在、AU6不足”，并由AU7或AU24等表现控制和泄漏。

### 惊讶

常见参考：`AU1 + AU2 + AU5 + AU26`。如果只是轻微吃惊，不要直接使用最高强度组合。

### 恐惧/紧张

可参考：`AU1 + AU2 + AU4 + AU5 + AU20 + AU26`，但实际使用时只挑与剧情一致的局部动作，避免整张脸同时拉满。

### 厌恶

可参考：`AU9 + AU10`，必要时辅以唇部收紧。

## 与说话口型的协调

这是AI视频里非常重要的一条：

- `AU24`强烈激活时，不要同时安排清晰的大幅开唇发音。
- `AU28`、明显抿唇、咬唇等动作应放在停顿或说话间隙，而不是和需要张口的音节重叠。
- `AU25`适合自然开唇与说话前准备，但不能替代真实口型。
- 情绪高潮可以发生在**台词前一拍、某个关键词、或说完后的余韵**，不必全部堆在发音瞬间。

## 与情绪导演的关系

FACS层负责回答：

> “脸上具体哪个动作发生了？”

情绪导演层负责回答：

> “为什么发生、什么时候发生、为什么先发生这个而不是那个？”

自然语言Prompt最终回答：

> “演员应该怎么演。”

因此，不要把FACS变成最终输出的“编码堆砌”，而要把它变成隐藏在背后的动作骨架。
